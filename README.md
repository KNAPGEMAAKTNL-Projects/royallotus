# Royal Lotus Massage

Concept website for **Royal Lotus Massage** — a mobile, professional Thai massage service in Tangier, Morocco. Authentic Thai therapists travel to the client's hotel, riad or villa with everything provided.

Single-page static site, deployed on Cloudflare Pages.

## Stack
- Static HTML / CSS / vanilla JS (single `index.html`)
- Google Fonts: Cormorant Garamond + Jost
- Cloudflare Pages (production branch `main`)

## Status
Demo / concept. The site is set to `noindex` and `robots.txt` disallows crawling until it goes live on the production domain.
